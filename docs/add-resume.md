# Add or replace the public résumé

A general one-page résumé (Developer & Data Analyst, November 2026) is published at
`public/resume/manoj-kumar-resume.pdf`. Keep it general — tailored résumés stay private.

To publish the file behind the existing `/resume` link:

1. Export the final document as a PDF.
2. Replace or add it at `public/resume/manoj-kumar-resume.pdf`.
3. Commit and push the file to `main`.

The `/resume` page automatically redirects to that PDF whenever it is present.
Until then, it provides a professional email-request route instead of a broken
download link.
